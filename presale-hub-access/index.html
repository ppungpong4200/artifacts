presale hub

ขอ tokenอ่านเอกสาร presale

ให้ AI ของคุณค้นและอ่านเอกสาร presale ได้ อ่านอย่างเดียว

ระบุทีมหรือข้อมูลที่อยากเห็น

ชื่อและช่องทางติดต่อใช้พิจารณาคำขอ และบันทึกไว้กับ token ที่อนุมัติ

ส่งคำขอแล้ว รอเจ้าของระบบอนุมัติ

เปิดหน้านี้ค้างไว้ได้ หน้านี้จะเปลี่ยนเองเมื่ออนุมัติ หรือกลับมาเปิดลิงก์เดิม

ที่อยู่ของหน้านี้ตอนนี้คือกุญแจของคำขอ อย่าส่งต่อให้ใคร

คำขอหมดอายุใน 14 วัน

อนุมัติแล้ว

กดรับ token เมื่อพร้อมติดตั้ง จะแสดงครั้งเดียว ถ้าหน้าปิดก่อนได้คัดลอก ต้องขอใหม่ รับได้ภายใน 7 วันหลังอนุมัติ


          
        

        
เก็บไว้เดี๋ยวนี้ หน้านี้ไม่แสดง token อีก ห้ามส่งต่อ ห้ามใส่ใน git หรือแชตกลุ่ม ถ้าหลุดให้แจ้งเจ้าของระบบเพื่อเพิกถอน


        

          
ติดตั้ง

          
Claude Code
            
คำสั่งนี้เก็บ token ไว้ในไฟล์ตั้งค่าของ Claude Code บนเครื่องคุณ

            

          
Codex CLI
            
macOS และ Linux

            
Windows PowerShell

          
โปรแกรมอื่นที่ต่อ MCP แบบ HTTP ได้
            
ใส่ URL นี้ และ header นี้

          
Claude Desktop (ยังไม่ได้ทดสอบกับแอปจริง)
            
ต้องมี Node.js 18 ขึ้นไป 1) ดาวน์โหลดไฟล์ตัวกลางนี้เก็บไว้ที่ใดก็ได้ 2) เติมส่วนนี้ใน claude_desktop_config.json โดยแก้ path ให้ตรง 3) ปิดแล้วเปิดแอปใหม่

            
            

          
ChatGPT
ยังต่อไม่ได้ ChatGPT รองรับ MCP แบบ OAuth หรือไม่มีการยืนยันตัวตนเท่านั้น ใช้ token แบบนี้ไม่ได้ ใช้ Claude หรือ Codex แทน


          
ลองใช้
