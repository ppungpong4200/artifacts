ขอ token อ่านเอกสาร presale

ให้ AI ของคุณ (Claude, Codex ฯลฯ) ค้นหาและอ่านเอกสาร presale ของ iPassion ได้ อ่านอย่างเดียว แก้ไขหรือสั่งงานระบบไม่ได้ เจ้าของระบบต้องอนุมัติก่อน และ token อยู่ได้ไม่เกิน 90 วัน

ข้อมูลนี้ส่งให้เจ้าของระบบคนเดียว เก็บเท่าที่ใช้พิจารณาและบันทึกว่าใครถือ token (คำขอที่ไม่อนุมัติหรือหมดอายุจะถูกลบใน 90 วัน)

ส่งคำขอแล้ว รอเจ้าของระบบอนุมัติ

เปิดหน้านี้ค้างไว้ได้ หน้านี้จะเปลี่ยนเองเมื่ออนุมัติ หรือกลับมาเปิดลิงก์เดิม (ที่อยู่ของหน้านี้ตอนนี้ คือกุญแจของคุณ อย่าส่งต่อให้ใคร)

คำขอหมดอายุใน 14 วัน

อนุมัติแล้ว

กดรับ token เมื่อพร้อมติดตั้ง จะแสดงครั้งเดียว ถ้ากดแล้วหน้าปิดก่อนได้คัดลอก ต้องขอใหม่ รับได้ภายใน 7 วันหลังอนุมัติ
